# fe3h-editor

Save editor for Fire Emblem: Three Houses v1.2.0.

Source and bundled Windows executables are based on [Falo's v1.2.0 Beta1 release](https://www.dropbox.com/s/8ip17sw610xkirh/FireEmblemThreeHouse_SaveEditor_v1.2.0_Beta1.7z?dl=1).

Open `FireEmblemThreeHouse.sln` in Visual Studio to build the .NET Framework 4.7.2 projects.
